## v1.4.5 更新

- 新增 NeoForge 加载器，支持创建实例、安装与模组过滤。
- 新增 Quilt 加载器，通过 Quilt Meta 生成配置并支持 Quilt 模组。
- NeoForge 版本与安装程序支持 BMCL Maven 镜像。
- 创建实例界面新增 NeoForge、Quilt 选项。

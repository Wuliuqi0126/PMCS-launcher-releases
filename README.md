## v1.4.9 更新

- playit 已登录用户在启动器重启后自动恢复守护进程。
- 通过 playit 本地 IPC 读取真实隧道列表。
- 自动匹配当前局域网端口的 `*.tun.ply.gg` / `*.playit.gg` 公网地址。
- 公网地址可复制，即使没有 launcher secret 也能显示已有隧道。

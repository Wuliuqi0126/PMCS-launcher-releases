## v1.4.0 更新

- 模组市场拆分为模组、光影、皮肤三个独立模块。
- 光影模块聚合 Modrinth 与 CurseForge，安装到 `shaderpacks`。
- 皮肤库支持导入 64×64 / 64×32 PNG、预览、删除和打开文件夹。
- 皮肤模块提供 NameMC、SkinMC、MinecraftSkins、Planet Minecraft 入口。
